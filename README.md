# SafeSphere

**Navigate with intelligence, not anxiety.**

SafeSphere is a safety-aware navigation and journey intelligence platform designed for women and vulnerable travelers. It provides real-time route analysis, active journey protection (Journey Guardian), and institutional-level aggregation for campuses and enterprises.

## Key Features
- **Explainable Routing**: Compare routes based on Fastest, Safest, or Balanced criteria, backed by a real-data SafeScore.
- **SafeScore Engine**: A dynamic 0-100 score computed from OpenStreetMap (OSM) Overpass API data (lighting, crowd proxy, safe zones) and historical district data (NCRB).
- **Journey Guardian**: Active tracking that alerts you to risk increases ahead and offers safer detours.
- **Emergency SOS**: Immediate alert system notifying trusted contacts with real-time location.
- **Institutional Command Center**: Aggregated, anonymized intelligence for security teams.
